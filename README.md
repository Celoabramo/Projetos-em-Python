# 🐍 Meus Estudos em Python

Repositório dedicado aos meus estudos de programação em Python. Aqui guardo exercícios, testes e pequenos projetos desenvolvidos ao longo do meu aprendizado.

---

## 📌 Sobre

Este repositório reúne códigos feitos para praticar lógica de programação, entender conceitos da linguagem Python e testar ideias.
Os arquivos podem variar entre exercícios simples até pequenos projetos.

---

## 📂 Organização

Os conteúdos estão separados por temas para facilitar o aprendizado:

* 📁 `fundamentos` → primeiros passos com Python (variáveis, entrada de dados, etc.)
* 📁 `condicionais` → uso de if, else, elif
* 📁 `loops` → estruturas de repetição (for, while)
* 📁 `funcoes` → criação e uso de funções
* 📁 `estruturas_dados` → listas, dicionários, tuplas
* 📁 `projetos` → pequenos projetos práticos
* 📁 `testes` → códigos experimentais

---

## 🧩 Projetos incluídos

* 📌 `Agenda de contatos.py` → programa simples para cadastrar, visualizar e gerenciar contatos
* ☕ `Cafeteria.py` → simulação de sistema de pedidos de uma cafeteria
* 🤖 `IATRADUTORA.py` → IA com API da google que traduz do portugues para o inglês
* 💵 `Vendas.py` → Aprendendo lista e matrizes
* 🔏 `nome&senha.py` → Primeiro projeto de nome e senha tirado do zero :)
---

## 🚀 Como executar os arquivos

1. Clone o repositório:

```
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Acesse a pasta:

```
cd seu-repositorio
```

3. Execute qualquer arquivo Python:

```
python nome_do_arquivo.py
```
